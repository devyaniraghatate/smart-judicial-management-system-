SMART JUDICIAL MANAGEMENT SYSTEM — UI PROTOTYPE

Files:
- index.html: page structure
- style.css: responsive layout and styling
- script.js: demo interactions and browser-local sample data

HOW TO RUN IN VS CODE
1. Extract the ZIP file.
2. Open the extracted SJMS_UI_Project folder in VS Code.
3. Open index.html in a browser, or install the Live Server extension and click "Go Live".
4. Navigate with the left sidebar.

FEATURES
- Dashboard with case counts and recent records
- File a case
- Search and filter cases
- Schedule hearings
- Record judgments
- Track case status by case ID
- Demo user list management
- Responsive layout for desktop and mobile

IMPORTANT
This is a frontend prototype. Records are saved in the browser's localStorage only.
There is no real PHP/MySQL backend, secure authentication, protected file upload, or production access control yet.
Use fictional sample data only. The report's proposed backend can be connected in a later step.
